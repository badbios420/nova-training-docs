## Goal of first wave

**Ship 5–10 live listings in one sitting** (45–90 min once items are in hand).  
Optimize for: **speed to cash**, not perfect titles or max price.

### Pick order (score each candidate 1–5, list highest first)

| Criterion | Prefer | Avoid first wave |
|-----------|--------|------------------|
| **Turn speed** | Common demand, easy ship | Niche / research buyers |
| **Price band** | ~$25–$200 (sweet ship vs effort) | <$15 (fees eat it) or huge freight |
| **Condition clarity** | Works / tested / complete | “Unknown if works” piles |
| **Photo easy** | One surface, good light | Tiny parts, glare-only chrome |
| **Emotional drag** | Easy to let go | Sentiment / “maybe later” |
| **Weight/size** | USPS Ground Advantage / small flat-rate | Freight, local-only unless stated |

**Rule:** If you hesitate >30s on “would I buy this used?” → skip first wave.

## 15-minute setup (once)

1. eBay app or browser logged in; **seller hub** open  
2. Default: **private listing style** you already use (auction vs BIN — pick one for whole wave)  
3. **Recommended first wave:** Buy It Now + offers on (faster cash than pure auction)  
4. Shipping: calculated or flat you already trust — don’t redesign policy tonight  
5. Phone charged; clear a **2×2 ft photo spot** + daylight or one lamp  
6. Boxes/poly mailers + tape in reach (or note “buy supplies tomorrow” and still list with realistic handling time)

---

## Per-item 5-minute loop

1. **Photo set (min 5):** front, back, label/model, flaw, in-hand/scale  
2. **Title pattern:**  
   `Brand Model KeySpec Condition — short hook`  
   Example shape: `Sony WH-1000XM4 Wireless Headphones Black — Tested Good`  
3. **Condition:** honest one-liner (works / battery life / scratches)  
4. **Price:**  
   - 30s sold comps on eBay  
   - Start **~10–15% under** clean comps if you want speed  
5. **Shipping weight** guess → print label later  
6. **Publish** → mark row Listed  

**No research rabbit holes.** If comps take >2 min, price from gut in band and move on.
